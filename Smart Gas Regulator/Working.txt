⚡ Working Logic (Step by Step)

Knob Position (Hall sensors):

At 0° → Servo OFF (regulator closed).

At 90° or 180° → Servo ON (regulator open).

Human Counter (IR sensors):

Entry IR → +1

Exit IR → –1

Counter never goes below 0.

Auto OFF Timer:

If knob is ON and human count = 0 → Start 5-min countdown.

If someone enters before 5 minutes → Cancel timer.

If no one enters → Regulator OFF (servo closes).

Manual Timers:

Button 1 → Run timer for 10 min.

Button 2 → Run timer for 20 min.

Button Stop → Cancel timer.

At end of timer → Servo OFF + Buzzer beep.
